# CZA Öğrenci ve Eğitimci Paneli — Google Apps Script

Bu klasör, CZA Sürüm 14 öğrenci ve eğitimci panelinin kaynak kodu arşividir.

- `Code.gs`: ortak sunucu ve veri katmanı
- `Index.html`: CZA Öğrenci Paneli
- `Egitimci.html`: CZA Eğitimci Paneli

## Kurulum

Apps Script proje ayarlarında `CZA_SPREADSHEET_ID` adlı Script Property oluşturun ve çalışma kitabı kimliğini sunucu tarafında tanımlayın. Kimlik, öğrenci kayıtları ve diğer gizli değerler güvenlik nedeniyle bu açık depoda tutulmaz.
